## Excel-Price-Processor
# What it is
A python script that runs through an excel sheet and creates a column with a discounted price. It also creates a chart based on your 

## Installation 
* Clone Repo: git clone https://github.com/jonathanrobin13/excel-price-processor.git
* Navigate to the folder: cd excel_price_processor
* Download library: pip install -r requirements.txt

## How to use it
- Have an excel file
- run the main.py 
- make sure the excel file is not open while the program is running
- open excel file once main.py is finished running
- see your updated file
